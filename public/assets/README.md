## 🚀 Cara Menambah / Mengganti Gambar

1. **Ganti Foto Proyek**: Taruh file di folder `public/assets/projects/` dengan nama yang sama (misal `project1.jpg` atau `project1.webp`).
2. **Ganti Foto Tim**: Taruh foto baru di `public/assets/team/` dengan nama yang sesuai (misal `dava.webp`, `frontend-lead.jpg`, `cofounder.jpg`, `frontend-senior.jpg`, `backend-lead.jpg`, `salim.jpg`, `dwiki.jpg`).
3. **Format yang Didukung**: `.webp`, `.jpg`, `.jpeg`, `.png`. Sistem otomatis mendeteksi format yang tersedia.
